About Me

My route into software wasn't the usual one. I graduated in Electrical and Electronics Engineering with an 8.51 CGPA, and somewhere along the way I realised I enjoyed debugging logic far more than debugging circuits. So I committed to it properly — an intensive Java Full Stack program at Tap Academy, followed by months of building projects on my own instead of only watching tutorials.

Most of my depth is on the backend. I'm comfortable with Core Java and OOP, collections, exception handling and multithreading, and I've built real applications on Servlets, JSP, JDBC and Spring Boot with Hibernate and MySQL behind them. I structure projects with layered MVC and the DAO pattern because separating concerns is what makes a codebase survivable after the first month.

On the frontend I work with HTML, CSS, JavaScript and React — enough to build responsive, accessible interfaces that do justice to the backend behind them. Every project in this portfolio was designed, built and deployed by me, from the database schema to the final layout.

To be honest about where I stand: I'm early in my career. I don't have production experience at scale yet, and I'm still learning cloud deployment, testing discipline and system design in depth. What I do have is consistency — 100+ DSA problems solved, nine shipped projects, and a habit of finishing what I start. I'm looking for a team where I can contribute real work and grow fast under people who build things properly.
